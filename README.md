# Spandan Saha — Portfolio

A personal portfolio for Spandan Saha, a Computer Science student interested in AI/ML, embedded systems, and software development. Built with Next.js, React, TypeScript, and Tailwind CSS.

## Portfolio sections

- Introduction and About
- Experience: Chrysalis – IEM Research Foundation
- Education: Institute of Engineering and Management; Sudhir Memorial Institute
- Skills: Python, Java, C/C++, SQL, PyTorch, Edge Impulse, Arduino IDE, Google Cloud Platform, GitHub
- Projects: Raahé and Password Generator
- Leadership, creative interests, and contact links

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

A GitHub Actions workflow runs the production build on pushes and pull requests to `main`.

## Deployment

Import this repository into Vercel and use the default Next.js build settings. No environment variables are required for the current site.

## Asset note

The hero uses your GitHub profile avatar. The portfolio includes a print-friendly resume page at `/resume`; use **Print / Save as PDF** in your browser to export it. This page is a web-formatted resume, not the original uploaded PDF.
